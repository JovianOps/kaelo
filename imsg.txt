Add a C ABI so non-Rust hosts can drive kaelo

Builds as cdylib/staticlib with a 10-symbol surface in include/kaelo.h:
open/close, run, eval, call0/call_int/call_float, last_error, host_fn0,
free_string. examples/game_host.c is a complete C host running a 600-frame
game loop against script functions, with a host-registered draw callback.

Verified with tests/c_abi.rs, which calls the exported symbols directly:
4 tests covering run+eval, per-frame calls, error reporting, and the host
callback (asserting it fires exactly twice). All 10 symbols confirmed present
in the built DLL export table.

No C compiler exists on this machine, so the .c example is shipped with build
commands but compiled by the consumer; the Rust tests cover the ABI itself.
